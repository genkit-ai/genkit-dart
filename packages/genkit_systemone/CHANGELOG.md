## 0.0.1

- Initial preview release: System One decision models served behind
  `generate`, with the output schema as the question set (`Choice`, `ScoreOf`,
  `Noul`, `NoulOf`, `decisionSchema`, `questionsSchema`), and the `SystemOne`
  plugin for TypeSafe, OpenRouter's Decisions API, Cloudflare Workers AI,
  Ollama, and any other server that speaks the protocol. A port of Genkit Go's
  `systemonex` plugin.
